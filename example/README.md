# The example

A small fictional app (`app/index.html`), its brand profile (`brand.json`), the storyboard, the cards spec and the
recording script Claude would write for a pull request, plus the finished video (`animatic.mp4`).

**About the design.** The example app's visual design is based on a design concept found on Pinterest and is used for demonstration only. Every name, text and number in it is fictional. If it is your design and you would like credit or want it removed, please open an issue.
